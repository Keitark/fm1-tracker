From a sound to a song

This workshop runs the same C input controller and LCD renderer as the firmware. It does not contact your FM-1.

  1. Explore the demo. Press PLAY/STOP, change the selected track with SELECT, then stop. The cursor follows the last heard row.
  2. Start fresh. Hold SEQ + REC for 600 ms. If the song has edits, release both and tap REC to confirm. EDIT cancels.
  3. Choose a sound. ENV opens the bank. KNOB1 browses, PRESETS chooses its song slot, FX copies it. Occupied slots ask before replacement.
  4. Write the beat. REC enables WRITE. Piano keys enter notes; KNOB1 moves rows, SELECT chooses tracks, KNOB4 sets entry step.
  5. Revise freely. SAVE + OCT− undoes, SAVE + OCT+ redoes. KNOB2 selects the field; KNOB3 changes its value.
  6. Make a variation. HOME opens orders. SEQ duplicates the pattern, FX appends its reference. ALGORITHM chooses the order. HOME returns.
  7. Inspect the sound. ARP opens Samples. KNOB2 chooses volume, finetune or loop points; KNOB3/4 edit them. Piano still auditions.
Find a control without leaving the device:
Hold SAVE for its shortcuts, or press SAVE + HOME for the built-in guide.

Simulator sessions are volatile. Download your MOD before closing this process. The physical firmware saves through its USB PC library service.
